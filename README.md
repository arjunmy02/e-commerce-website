# 🛒 E-Commerce Website

A full-stack **E-Commerce Website** built using **HTML, CSS, JavaScript, Spring Boot, and MySQL**. The application provides a modern online shopping experience with a responsive frontend and a Spring Boot backend.

---

## 📌 Project Overview

This project is designed to simulate a real-world e-commerce platform where users can browse products, search for items, view product details, and manage a shopping cart. The backend is developed using Spring Boot and stores product information in a MySQL database.

---

## ✨ Features

* 🛍️ Browse available products
* 🔍 Search products
* 📄 View product details
* 🛒 Add products to cart
* ❌ Remove products from cart
* 💾 Shopping cart using Local Storage
* 📱 Responsive user interface
* 🔗 REST API integration
* 🗄️ MySQL database connectivity

## 🚀 Getting Started

### Clone the Repository

```bash
git clone https://github.com/arjunmy02/e-commerce-website.git
```

### Backend

1. Create a MySQL database.
2. Configure your database credentials in `application.properties` or `application.yml`.
3. Run the Spring Boot application.

### Frontend

Open the frontend project in your browser or run it using the Live Server extension in Visual Studio Code.
